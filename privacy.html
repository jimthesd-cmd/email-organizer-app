Privacy policy

Email Organizer is a personal tool used only by its owner.

  • It uses Google Calendar access only to create, update or remove events in the owner's own calendar.
  • It does not sell, share or transfer Google user data to anyone.
  • Data stays on the owner's private server. Access can be removed at any time in the Google Account under Security → Third-party connections.

Google user data is used in line with the Google API Services User Data Policy, including the Limited Use requirements.
